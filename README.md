DCA vs. Lump-Sum Investing

Project Overview

This project compares two investment strategies: Dollar-Cost Averaging (DCA) and Lump-Sum Investing.

Using historical Tesla (TSLA) stock data, the project simulates how a $12,000 investment would perform under each strategy over a specified period.

Investment Strategies

Lump-Sum Investing: Investing the entire amount at the beginning of the investment period.

Dollar-Cost Averaging: Dividing the initial investment into equal monthly contributions.

Tools & Technologies

Python

Jupyter Notebook

Pandas

Matplotlib

Historical Stock Market Data

Objective

Analyze how investment timing affects portfolio performance and compare the ending portfolio values of both strategies.

Files

DCA vs Lump-Sum.ipynb: Contains the Python simulation, calculations, and results.
